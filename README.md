# Private Music

Private Music — неофициальный клиент VK Музыки для iPhone, написанный на
SwiftUI. Проект развивает **decoder-dev**.

## Возможности

- вход в VK через изолированное веб-окно и хранение сессии в Keychain;
- главная с историей, рекомендациями, миксами и плейлистами VK;
- системный Search Tab на iOS 26.5+ (включая iOS 27) и совместимый поиск
  на старых версиях;
- поиск треков и исполнителей с историей запросов;
- медиатека, плейлисты, очередь и восстановление воспроизведения;
- офлайн-загрузка отдельных треков и целых плейлистов с обложками,
  прогрессом и отменой; данные изолированы по VK-аккаунту;
- настраиваемый лимит офлайн-хранилища от 5 до 100 ГБ и безопасный автокэш
  на Wi‑Fi с очисткой давно не прослушанных записей;
- edge-to-edge плеер без системных чёрных полей, фоновое аудио,
  экран блокировки, AirPlay и Bluetooth;
- пауза при снятии наушников / AirPods по
  [Responding to audio route changes](https://developer.apple.com/documentation/avfaudio/responding-to-audio-route-changes)
  (`routeChangeNotification`, `oldDeviceUnavailable`) и Automatic Ear Detection;
- тексты песен из VK, LRCLIB и Genius;
- 10-полосный эквалайзер и настройки воспроизведения;
- отправка настоящего MP3- или M4A-файла через системное меню «Поделиться»
  без подмены ссылкой; во время подготовки файла офлайн-загрузки и автокэш
  временно останавливаются и скрываются из интерфейса;
- чёрная и белая темы;
- системный TabView Liquid Glass, сворачиваемая навигация, Search Tab и
  адаптивный мини-плеер на iOS 26.5+; совместимый интерфейс на iOS 16–26.4;
- интерфейс на русском и английском языках;
- Privacy Manifest без аналитики и отслеживания.

## Сборка

Для локальной сборки нужен macOS с Xcode 27 и XcodeGen:

```bash
brew install xcodegen
git clone https://github.com/decoder-dev/PrivateMusic2.git
cd PrivateMusic2
bash ./scripts/bootstrap.sh
open PrivateMusic.xcodeproj
```

CI прогоняет unit-тесты на Xcode 26.5 и собирает релизный IPA на
GitHub-hosted runner `xcode-27` с iOS 27 SDK.

Для установки на физический iPhone укажите свою команду разработчика в
Signing & Capabilities. Репозиторий также собирает неподписанный IPA через
GitHub Actions. Такой архив перед установкой необходимо подписать собственным
сертификатом.

Структурные проверки можно запустить на Windows, Linux или macOS:

```bash
python scripts/validate_project.py
python scripts/validate_localizations.py
```

## Важно

Private Music не содержит паролей, пользовательских токенов или чужих
`client_secret`. Приватные методы VK Музыки не являются публичным стабильным
API и могут измениться. Используйте только собственную учётную запись и не
публикуйте полученный токен.

Проект не связан с VK и не распространяет музыкальные файлы. Экспорт работает
только для потока, доступ к которому уже получен текущей пользовательской
сессией. Офлайн-загрузка поддерживает как прямые аудиофайлы, так и HLS через
системный загрузчик AVFoundation. HLS-пакет предназначен только для локального
воспроизведения: его нельзя простым переименованием превратить в MP3. Поэтому
«Поделиться» отправляет прямой MP3 либо экспортирует доступный незашифрованный
поток в M4A. Защищённый DRM-поток не обходится и не маскируется под аудиофайл.
