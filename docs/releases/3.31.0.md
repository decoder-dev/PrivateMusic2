# Private Music 3.31.0

## Музыка на iPhone

- Импорт MP3, M4A, AAC, WAV и FLAC через приложение «Файлы». Сохранённые копии играют без интернета через обычный плеер.
- Название, исполнитель, альбом и обложка считываются из файла. Одинаковые файлы повторно не добавляются.
- Импортированная музыка остаётся на устройстве: она не загружается в VK, не транслируется в статус и не попадает в отчёты VK о прослушиваниях.
- При удалении из Private Music исходный файл сохраняется.

## Плеер

- Если обложки нет, плеер показывает лаконичную монограмму исполнителя без пустой карточки и большой музыкальной заглушки.
- Видимая кнопка закрытия, в том числе при увеличенном размере текста.
- Быстрые свайпы по обложке распознаются по направлению и скорости. Свайп к предыдущему треку переключает трек; кнопка «Назад» сохраняет привычную перемотку к началу.
- Копирование названия и исполнителя из плеера и меню трека.

## Установка

IPA не подписан. Для установки требуется подпись через Sideloadly, AltStore или другой совместимый инструмент.

- `…-iphone-unsigned.ipa` — iPhone и виджет, без приложения Watch.
- `…-unsigned.ipa` — iPhone, виджет и Watch.
- `…-dSYMs.zip` — символы отладки соответствующей сборки.

Для обмена данными с виджетом подпись приложения и расширения должна поддерживать App Group `group.com.dec.privatemusic2`.
