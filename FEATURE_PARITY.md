# Feature parity

Сравнение основано на статическом анализе `Private Music 1.1` и исходниках
Private Music 2.7. Код и закрытые ключи старого приложения не копировались.

| Возможность | Legacy 1.1 | Private Music 2.7 |
| --- | --- | --- |
| Моя музыка и рекомендации | Да | Да |
| Главная страница | Каталог VK | Безопасная лента рекомендаций и плейлистов |
| Поиск треков | Да | Да |
| Поиск и карточка исполнителя | Да | Да |
| Плейлисты и их треки | Да | Да |
| Создание, изменение, удаление плейлиста | Да | Да |
| Добавление/удаление треков | Да | Да |
| Загрузка обложки плейлиста | Да | Пока нет |
| Подписка на чужой плейлист | Да | Пока нет |
| Очередь, play next | Да | Да |
| Shuffle, repeat, seek | Да | Да |
| Фоновое аудио и Now Playing | Да | Да |
| Тексты | Genius с fallback VK | VK с fallback LRCLIB |
| Экспорт прямого аудиофайла | Да | Да, до 150 МБ; HLS не обходится |
| Темы | Нет подтверждения | 5 тем и 3 режима интерфейса |
| Liquid Glass | Нет подтверждения | Нативный iOS 26 + material fallback |
| Эквалайзер | Нет подтверждения | Реальный 5-band DSP через audio tap |
| Таймер сна | Нет подтверждения | Да |
| Авторизация | Пароль/OTP и чужой Android secret | Веб-вход VK по телефону; токен в Keychain |
| Восстановление закрытых URL потоков | Да | Да, локально для своей сессии |
| Аналитика и реклама | Не найдены | Нет |

## Намеренные границы

Legacy-приложение представлялось Android-клиентом VK, содержало чужой
`client_secret` и перехватывало CAPTCHA-ответы. Эти механизмы не переносятся.
Веб-вход 2.7 использует непостоянное окно VK и не читает поля формы. После
прямого обмена с `login.vk.ru` cookies удаляются. Это удобнее ручного импорта,
но остаётся неофициальной интеграцией. Для официальной кнопки VK ID нужны
собственные `app_id`, redirect URI и разрешения приложения `decoder-dev`.
